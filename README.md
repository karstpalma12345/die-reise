# Die Reise – Karst & Carla
Karst & Carla – Eine gemeinsame Reise zur deutschen Sprache.

**Status: Fase 1 (basis).** Navigatie, startscherm, personages, logo en lokale opslag (IndexedDB). Leren, verhaal, spreken en voortgang volgen in fase 2–5.

## Op GitHub zetten (zonder terminal)
1. Maak een gratis account op github.com en kies *New repository* (naam bv. `die-reise`, *Public*).
2. Klik *uploading an existing file*, sleep de **inhoud** van de uitgepakte map erin (ook de verborgen map `.github`), en klik *Commit changes*.
3. Ga naar *Settings → Pages* en kies bij *Source*: **GitHub Actions**.
4. Open het tabblad *Actions*; na ± 2 minuten staat er een groene vink. Je adres is `https://JOUWNAAM.github.io/die-reise/`.

## Op je iPhone
Open het adres in **Safari** → deelknop → *Zet op beginscherm*.

## Je gegevens
Alles staat alleen op je toestel (IndexedDB). Back-up exporteren/importeren volgt in fase 5/6.
